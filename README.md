# AI Coding 工程实践档案

本仓库作为简历的**证据链补充**，展示 AI Coding / AI Agent 应用开发中的实际工程实践成果。

## 仓库定位

- **目标读者**：面试官、HR、技术评审、对我项目数据/工作流感兴趣的研究者
- **核心价值**：可验证的工程数据、协作流程、问题解决案例
- **三个原则**：
  1. 只放脱敏后的数据与文档
  2. 只放对比结果与关键样本，不放全量原始数据
  3. 代码永远指回原仓库，不在此复制

## 目录结构

```
├── methodologies/          # 方法论与流程
│   ├── human-ai-workflow/  # 人机协同工作流
│   └── failure-analysis/   # 失败模式分析框架
├── cases/                  # 典型案例
│   ├── performance/        # 性能优化案例
│   └── debugging/          # 问题排查案例
├── metrics/                # 量化指标
│   └── benchmarks/         # 性能基准与对比
├── logs/                   # 日志样本（脱敏）
└── demos/                  # 演示视频与截图
```
