3 个典型调试案例

案例 1：TCP 熔断器 — 从"每 14 分钟人工重启"到"2.8h 内 12 次自愈"

问题：ESP32 与树莓派 Hub 的 TCP 连接频繁中断后无法自动恢复，必须手动重启。

根因：熔断器缺少 HALF-OPEN 状态，标志位置位后没有清除路径 → 单向闩锁，永不自愈。

修复前后对比
维度 修复前 修复后
人工干预 每 14 分钟重启一次 零干预
自愈能力 无，永久失联 12/12 次自动恢复
最长失联 无限（直到人工重启） 最多 120s（两次探测）

关键洞察：熔断器必须是三态的（OPEN / CLOSED / HALF-OPEN），清除语句不能被开关本身守卫。

案例 2：堆碎片化调试 — 在悬崖上爬坡与 Git 锚点救场

问题：用户报告切换模式时出现卡顿、壁纸加载失败等异常。指标显示"很健康"（loopMs 平均 125ms）。

陷阱：在坏基线上做了三组对照实验，P95 延迟全部 2494~2825ms → 三次优化，零效果。

归因断了的表现
  • 每次测量的差异里混着"这次的改动"和"原本就存在的其他病"
  • 无法判断"是这个改动的功劳，还是原来就这样"
  • 我的失误：怕丢工作，只关闭功能开关 → 半回退 = 最坏状态

转折：用户坚持真回退到 Git 锚点（git archive 到临时目录编译烧录）。

在干净基线上逐一击破
维度 在坏基线上调试 在锚点基线上调试
优化次数 3 次 1 次修 1 个 bug
有效改善 0 次 4 条判据全过
归因 断裂（混着其他病） 清晰（单一变量）

关键洞察：指标必须匹配用户可感的量（尾部延迟 vs 平均值）。锚点成本 = 一个 git tag；不建锚点成本 = 整轮调试走弯路。

案例 3：上传非原子性 — 断电毁数据与备份恢复机制

问题：网页上传壁纸时若断电或断网，原图片被损坏，无法恢复。

根因：UPLOAD_FILE_START 就直接打开目标文件写入 → 立即覆盖旧数据。中途断电 → 既不是新文件也不是旧文件。

真机 A/B 实证
  • A 组（修复前）：上传中断后 sha256: 2914fa25... → 025d5f3e... ← 文件被毁
  • B 组（修复后）：上传中断后 sha256: 2914fa25... → 2914fa25... ← 完全未变

修复策略：三阶段原子替换

  1. 写入临时文件 + 校验 sha256
  2. 原子替换：目标→.bak ⇒ tmp→目标 ⇒ 删.bak
  3. 开机自动恢复：检测 .bak 存在 → 目标损坏 → 从备份恢复

关键洞察：错误方案"失败就先删目标"会产生不可恢复窗口。备份文件（.bak）绝不能进开机自动删除名单。

💡 共性方法论： 测量—证伪—修复—复测闭环 / Git 锚点与逐一击破 / 真机 A/B 实证 / 指标必须匹配用户可感的量

人在环多 Agent 协同流程

协同角色分工

角色 负责范围 典型任务
人（主导） 架构设计（端-边-云布局）、需求拆解、任务路由、冲突裁决、真机验收 定义"什么是对的"、系统边界、最终验收

OpenClaw Linux 侧服务开发、系统集成 树莓派 Python 服务、企微 Bot
Work Buddy 低风险辅助任务 文档整理、数据提取
Codex (GPT) 独立外部复核 发布前审查、缺陷发现

工作流程：接口契约 + 分阶段验收

  1. 需求拆解与路由：识别风险等级 → 分配给合适的 Agent
  2. 接口契约定义：人工审查跨系统边界（HTTP 路径、JSON 字段、超时策略）
  3. 并行开发：各 Agent 独立实现 → 单侧验收（编译/启动/单元测试）
  4. 集成验收：真机测试（人工操作）→ 观察日志 + 屏幕 + 网络抓包
  5. 外部复核：发布前调用独立模型 → 给源码不给结论 → 逐条回代码验真伪

关键协同模式

跨系统协同（Windows ↔ Linux）

  • 人定义接口契约 → 两个 Agent 各自实现 → 人工集成测试
  • 不让两个 Agent 直接通信，所有跨界面信息经人工转达

独立复核（外部模型）

  • 给源码不给结论 → 要求指出行号 → 逐条回代码验真伪
  • 6 轮收敛：18 → 9 → 7 → 4 → 4 → 2（累计 44 条缺陷）

测量驱动迭代

  • 先测量建立基线 → AI 提出假设 → 设计可证伪实验 → 数据验证
  • 架构方向可假设，落地必须实测；小样本结论只能当假设

成本优化策略

  • 复用上下文：同一问题域的连续任务在同一会话
  • 分级处理：简单任务用轻量模型，复杂推理用顶级模型
  • 外部复核按需：发布前才调用独立模型，不是每次改动
  • 避免重复工作：Git 锚点 + 增量修复，不推倒重来
